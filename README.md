# Employee Attrition Prediction (In Progress)

A Machine Learning project that predicts whether an employee is likely to leave the company based on HR data.

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Streamlit

## Planned Features

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Employee Attrition Prediction Model
* Interactive Streamlit Dashboard
* Model Performance Evaluation
